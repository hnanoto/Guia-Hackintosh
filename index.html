Requisitos do Sistema

Certifique-se de que seu hardware é compatível antes de começar

Atenção: Nem todo hardware é compatível com macOS. Verifique cuidadosamente a compatibilidade antes de prosseguir.

CPU Compatíveis

Processadores Intel suportados:

  • Intel 8ª geração (Coffee Lake) ou superior
  • Alder Lake (12ª gen) com CPU spoofing
  • Raptor Lake (13ª gen) com CPU spoofing
  • AMD Ryzen (suporte limitado)

GPU Compatíveis

Placas de vídeo suportadas:

  • AMD RX 6000/7000 series (RDNA 2/3)
  • AMD RX 5000 series (RDNA 1)
  • AMD Vega/Polaris
  • Intel iGPU (HD/UHD 600+)
  • NVIDIA (sem suporte)

Outros Requisitos

Hardware adicional necessário:

  • 16GB+ RAM (recomendado)
  • SSD NVMe ou SATA
  • USB 16GB+ para instalador
  • Conexão de internet

Escolhendo o SMBIOS Correto

SMBIOS define qual Mac seu Hackintosh vai emular

Atualização 2024: Para macOS Sequoia 15.x e Tahoe 26.x, MacPro7,1 é a escolha recomendada para desktop com GPU dedicada AMD.
Hardware SMBIOS Recomendado Compatibilidade Observações
Desktop + AMD GPU dedicada MacPro7,1 Sequoia 15.x ✅
Tahoe 26.x ✅		 Melhor para RX 6000/7000
Desktop + AMD GPU (alternativa) iMacPro1,1 Sequoia 15.x ✅
Tahoe 26.x ⚠️		 Pode ser descontinuado
Desktop + Intel iGPU iMac20,1 / iMac20,2 Sequoia 15.x ✅ Para 10ª geração Intel
Laptop + AMD GPU MacBookPro16,1 Sequoia 15.x ✅ Para laptops potentes
Laptop + Intel iGPU MacBookPro16,2 Sequoia 15.x ✅ Para laptops comuns

Regras Importantes para SMBIOS

  • MacPro7,1: NÃO precisa de agdpmod=pikera com NootRX.kext
  • iMacPro1,1: Requer agdpmod=pikera com GPUs Navi (se não usar NootRX)
  • iMac SMBIOS: Assume presença de iGPU
  • Sem iGPU: Use MacPro7,1 ou iMacPro1,1
  • Gere novos seriais: Use GenSMBIOS para criar seriais únicos

Limitações de Hardware

Entenda o que funciona e o que NÃO funciona antes de começar

⚠️ LEIA ISTO PRIMEIRO!
Nem todo hardware é compatível com macOS. Esta seção lista as limitações conhecidas para evitar frustrações. Verifique seu hardware ANTES de prosseguir!

🔴 Suporte de CPU

CPUs Suportadas:
  • Intel Desktop: Yonah até Comet Lake (10ª Gen)
  • Intel HEDT/Server: Nehalem até Cascade Lake-X
  • Intel Laptop: Arrandale até Ice Lake
  • AMD Desktop: Bulldozer (15h), Jaguar (16h) e Ryzen (17h)
❌ NÃO Suportados:
  • Intel Atom, Celeron, Pentium Mobile - Não funcionam
  • AMD Laptops - Nenhum modelo suportado
  • AMD: Nem todos os recursos do macOS funcionam (ver abaixo)

Requisitos de Arquitetura:

Recurso Requisito macOS
SSE3 Obrigatório para todas as versões 10.4.1+
SSSE3 Obrigatório para 64-bit 10.6+
SSE4.2 Obrigatório (emulação disponível) 10.14+
AVX2 Obrigatório (sem workaround) 13.0+ (Ventura)
🚫 macOS Ventura (13.0+) e Sonoma (14.0+):
CPUs anteriores a Haswell (4ª Gen Intel) NÃO são mais suportadas devido ao requisito de AVX2. Isso inclui Ivy Bridge, Sandy Bridge e anteriores.

Limites de Core/Thread:

  • OS X 10.10 e anterior: Máximo 24 threads
  • OS X 10.11+: Máximo 64 threads
  • Workaround: Use cpus= boot-arg ou desabilite Hyperthreading

🎮 Suporte de GPU

📚 Guia Completo:
Consulte o GPU Buyers Guide para informações detalhadas sobre compatibilidade de GPUs.

⚠️ GPUs Dedicadas em Laptops:

  • 90% das GPUs dedicadas em laptops NÃO funcionam devido a gráficos comutáveis (Optimus/Switchable Graphics)
  • A GPU dedicada deve ser desabilitada e desligada na maioria dos casos
  • Saídas externas (HDMI, DP) podem ou não funcionar dependendo do laptop
  • Alguns laptops raros não têm gráficos comutáveis e podem funcionar (se a GPU for suportada)

Suporte por Fabricante:

Fabricante Status Observações
AMD (Polaris/Vega/Navi) Excelente RX 400/500/5000/6000/7000 funcionam bem
NVIDIA (Kepler) Limitado GTX 600/700 funcionam até Big Sur
NVIDIA (Maxwell+) Não Suportado GTX 900/1000/2000/3000/4000 não funcionam
Intel (iGPU) Bom HD/UHD Graphics funcionam (exceto Arc)

💾 Suporte de Armazenamento

✅ Funcionam Bem:
A maioria dos drives SATA e NVMe funcionam perfeitamente no macOS.
⚠️ Drives Problemáticos:
  • Samsung PM981/PM991 - Causam kernel panic, requerem NVMeFix.kext (ainda pode ter problemas)
  • Micron 2200S - Mesmos problemas que PM981/PM991
  • Samsung 970 EVO Plus - Problemas resolvidos com atualização de firmware
  • Intel 600p - Pode causar problemas (660p funciona bem)
  • Intel Optane Memory - Não suportado para aceleração de HDD
# Solução para PM981/PM991/Micron 2200S # Adicione NVMeFix.kext em EFI/OC/Kexts/ # Nota: Ainda pode ter problemas de boot! # Recomendação: Substitua o drive se possível

🌐 Suporte de Rede

Ethernet (Com Fio):

Praticamente todos os adaptadores Ethernet têm suporte, seja nativo ou via kexts da comunidade.
Exceções que requerem configuração:
  • Intel I225-V 2.5Gb - Requer device properties
  • Intel I350 1Gb - Requer device properties
  • Intel 10Gb (X520/X540) - Workarounds disponíveis
  • Mellanox/Qlogic - Não suportados

Wi-Fi e Bluetooth:

⚠️ Laptops:
A maioria dos cartões Wi-Fi em laptops (Intel/Qualcomm) não são nativamente suportados.
Marca Status Observações
Broadcom Melhor Opção Suporte nativo, funciona perfeitamente
Intel Não Oficial Requer AirportItlwm/IntelBluetoothFirmware
Atheros Limitado Apenas até High Sierra
Qualcomm Não Suportado Sem drivers disponíveis

🔧 Outros Componentes

❌ Não Suportados:
  • Sensores de Impressão Digital - Touch ID não pode ser emulado
  • Windows Hello (I2C) - Conectado via iGPU, não funciona
  • Windows Hello (USB) - Pode funcionar apenas como câmera
  • Intel Smart Sound Technology - Microfone interno não funciona
  • Combo Headphone Jack - Entrada de áudio pode não funcionar
⚡ Thunderbolt 3/4:
Suporte ainda é instável, especialmente com controladores Alpine Ridge. Hotplug pode causar kernel panics. Para usar USB-C, conecte no boot e mantenha conectado. Desabilitar Thunderbolt na BIOS resolve o problema.

🔌 Suporte de Placas-Mãe

Na maioria dos casos, todas as placas-mãe são suportadas desde que a CPU seja compatível.
⚠️ Placas MSI 500-series AMD:
Placas A520, B550 e X570 têm problemas com macOS Monterey+. Dispositivos PCIe não são enumerados corretamente. Recomenda-se Big Sur ou anterior.
✅ Atualização: Corrigido nas últimas versões dos patches AMD vanilla!

Instalação Passo a Passo

Guia completo para criar sua EFI do zero

0. Criar USB (Windows/macOS)

Use nossa ferramenta exclusiva para baixar e criar o instalador:

Baixar macOS Recovery

1. Download do OpenCore

Baixe a versão mais recente do OpenCore:

https://github.com/acidanthera/OpenCorePkg/releases

Versão recomendada: 1.0.5 ou superior

2. Estrutura da EFI

Crie a seguinte estrutura de pastas:

EFI/ ├── BOOT/ │ └── BOOTx64.efi └── OC/ ├── ACPI/ ├── Drivers/ ├── Kexts/ ├── Resources/ ├── Tools/ ├── OpenCore.efi └── config.plist

3. Drivers UEFI

Adicione os drivers essenciais em EFI/OC/Drivers/:

  • OpenRuntime.efi (obrigatório)
  • HfsPlus.efi (HFS+ support)
  • OpenCanopy.efi (GUI boot picker)
  • ResetNvramEntry.efi (reset NVRAM)

4. Kexts

Adicione os kexts necessários em EFI/OC/Kexts/:

  • Lilu.kext
  • VirtualSMC.kext + plugins
  • WhateverGreen.kext OU NootRX.kext
  • AppleALC.kext
  • Kexts de rede (Ethernet/WiFi)
  • CpuTopologyRebuild.kext (se 12ª/13ª gen)

5. Config.plist

Configure o config.plist usando:

  • ProperTree (editor recomendado)
  • Use Sample.plist como base
  • Configure SMBIOS com GenSMBIOS
  • Adicione boot-args necessários
  • Configure quirks para seu hardware

6. Boot e Instalação

Passos finais:

  • Copie EFI para USB
  • Configure BIOS (veja seção abaixo)
  • Boot pelo USB
  • Instale macOS
  • Copie EFI para disco interno

Configurações da BIOS

Configurações essenciais para funcionamento correto

Desabilitar

  • Fast Boot
  • Secure Boot
  • CSM/Legacy Boot
  • Intel SGX
  • Intel PTT/fTPM
  • CFG Lock (se possível)

Habilitar

  • Above 4G Decoding (CRÍTICO!)
  • Resizable BAR (ReBAR)
  • XHCI Hand-off
  • VT-x (Virtualization)
  • VT-d (pode manter habilitado)
  • UEFI Boot Mode

GPU Settings

  • Primary Display: PCIe
  • DVMT Pre-Allocated: 64MB+
  • iGPU: Disabled (se usar dGPU)
  • iGPU Multi-Monitor: Disabled

Boot Arguments Importantes

Argumentos de boot para diferentes situações

Boot-arg Função Quando usar
-v Verbose mode (mostra log de boot) Debug e instalação
keepsyms=1 Mantém símbolos em kernel panic Debug de problemas
debug=0x100 Desabilita watchdog (evita reboots) Debug de kernel panics
alcid=X Define layout de áudio (X = número) Configuração de áudio
agdpmod=pikera Fix tela preta GPUs Navi ⚠️ NÃO usar com NootRX!
-igfxvesa Modo VESA para iGPU Problemas com iGPU
npci=0x2000 Fix PCI configuration Problemas de boot
Importante: Com MacPro7,1 + NootRX.kext, você NÃO precisa de agdpmod=pikera. O fix já está incluído no NootRX!

Perguntas Frequentes

Respostas para dúvidas comuns

Qual SMBIOS devo usar?

Para desktop com GPU AMD dedicada: MacPro7,1 (recomendado para Sequoia/Tahoe) ou iMacPro1,1. Para desktop com iGPU Intel: iMac20,1/20,2.

Preciso de agdpmod=pikera?

NÃO se você usar MacPro7,1 + NootRX.kext! O fix já está incluído no NootRX. Apenas iMac/iMacPro SMBIOS sem NootRX precisam.

RX 6700 XT funciona no macOS?

SIM! Mas precisa do NootRX.kext. Não tem suporte nativo, mas com NootRX funciona perfeitamente no Sequoia 15.x.

Alder Lake (12ª gen) funciona?

SIM! Mas precisa de CPU spoofing (emular Comet Lake) e CpuTopologyRebuild.kext para E-cores funcionarem.

WiFi Intel funciona?

SIM! Use itlwm.kext + HeliPort.app. Mas AirDrop/Handoff não funcionam. Para funcionalidade completa, use Broadcom.

Como atualizar OpenCore?

Baixe nova versão, substitua OpenCore.efi e drivers, compare config.plist com Sample.plist usando OCConfigCompare, atualize kexts.

Solução de Problemas

Como resolver erros comuns durante o boot

Tela preta após boot?
  • Verifique se está usando NootRX.kext (para RX 6000/7000)
  • Remova agdpmod=pikera se usar MacPro7,1 + NootRX
  • Verifique se WhateverGreen e NootRX não estão juntos
  • Confirme que Above 4G Decoding está habilitado na BIOS
Kernel Panic ao bootar?
  • Adicione debug=0x100 keepsyms=1 aos boot-args
  • Verifique se todos os kexts estão atualizados
  • Confirme que Lilu.kext está carregando primeiro
  • Verifique quirks do Kernel no config.plist
Áudio não funciona?
  • Verifique se AppleALC.kext está instalado
  • Configure layout-id correto em DeviceProperties
  • Teste diferentes layouts (comum: 1, 7, 11, 13)
  • Adicione alcid=X aos boot-args (X = layout)

1. Mapeamento USB (CRÍTICO)

O mapeamento USB é ESSENCIAL para estabilidade, sleep e compatibilidade de dispositivos.

Por que mapear USB?

  • macOS tem limite de 15 portas USB
  • Previne problemas de sleep/wake
  • Melhora estabilidade geral do sistema
  • Corrige problemas com Bluetooth/WiFi
  • Necessário para iServices funcionarem

Ferramentas para Mapeamento

Ferramenta Plataforma Dificuldade Recomendado
USBToolBox Windows + macOS Fácil ✅ Sim
Hackintool macOS Média ✅ Sim
USBMap macOS Avançada ⚠️ Avançado
# USBToolBox - Método Recomendado # Download: https://github.com/USBToolBox/tool # No Windows: execute Windows.exe # No macOS: python3 USBToolBox.py # Passos: # 1. Escolha "D" para descobrir portas # 2. Conecte dispositivos em cada porta # 3. Escolha "S" para selecionar portas # 4. Escolha "K" para gerar kext # 5. Copie UTBMap.kext para EFI/OC/Kexts/
Importante: Remova XhciPortLimit quirk após mapear USB!

2. Corrigindo Sleep/Wake

Configurações para sleep e wake funcionarem perfeitamente.

Configurações pmset

# Desabilitar hibernação sudo pmset -a hibernatemode 0 sudo rm /var/vm/sleepimage sudo mkdir /var/vm/sleepimage # Desabilitar Power Nap sudo pmset -a powernap 0 # Desabilitar wake on LAN sudo pmset -a womp 0 # Configurar darkwake sudo pmset -a darkwake 0 # Verificar configurações pmset -g

Configurações BIOS para Sleep

  • Desabilitar Wake on LAN
  • Desabilitar USB Wake
  • Habilitar XHCI Hand-off
  • Desabilitar ErP (se disponível)

Troubleshooting Avançado (Culprits)

Displays & Laptops
  • Lid Wake (HP/Skylake+): Fix random wake caused by lid. Use SSDT-HP-FixLidSleep.
  • Fix Temp: sudo pmset -a lidwake 0
RTC (Real Time Clock)

Fix "BIOS Restarted in Safemode" on Z390+.

  • Fix 1: DisableRtcChecksum (Kernel -> Quirks)
  • Fix 2: RTCMemoryFixup.kext + rtcfx_exclude=58-59
NVMe & USB
  • Avoid: Samsung PM981/PM991, Micron 2200S
  • Fix: Use NVMeFix.kext
  • USB: Map USB ports properly (Max 15)
Darkwake boot-args

Try different values if sleep fails 1 sec after wake:

darkwake=0, 1, 2, 3, 8, 10, 512

Cosméticos (OpenCanopy & Dicas)

Deixe seu Hackintosh com visual premium durante o boot.

Habilitar Interface Gráfica (OpenCanopy)
  1. Baixe OcBinaryData (pasta Resources).
  2. Adicione OpenCanopy.efi em Drivers.
  3. Config.plist -> Misc -> Boot -> PickerMode: External.
  4. Config.plist -> Misc -> Boot -> PickerAttributes: 17.
Habilitar Som de Boot (Chime)
  1. Habilite o driver AudioDxe.efi em UEFI -> Drivers.
  2. UEFI -> Audio -> AudioSupport: True.
  3. UEFI -> Audio -> AudioCodec: 0.
  4. UEFI -> Audio -> AudioOutMask: -1.
  5. NVRAM -> 7C436110-AB2A-4BBB-A880-FE41995C9F82 -> SystemAudioVolume: 46.
Ocultar Texto de Verbose (-v)

Remova apenas após seu sistema estar 100% estável!

  • NVRAM -> UUID -> boot-args: Remova -v.

Manutenção e Segurança

Guia para manter seu Hackintosh seguro e atualizado

Como Atualizar (Seguro)

Siga esta ordem para evitar quebra do sistema:

  • 1. Faça backup da pasta EFI funcional no pendrive.
  • 2. Atualize Kexts primeiro.
  • 3. Atualize OpenCore (BOOTx64.efi, OpenCore.efi, Drivers).
  • 4. Valide config.plist com OCConfigCompare.
  • 5. Só então atualize o macOS.

Segurança (SIP & FileVault)

SIP (System Integrity Protection)

Desabilite (csr-active-config: FF0F0000) apenas para instalar kexts em /System (Root Patching). Para uso normal, mantenha habilitado (00000000).

FileVault (Criptografia)

Requer configuração complexa (Misc -> Security -> Vault). Não ative sem ler a documentação oficial, ou você perderá acesso aos dados.

ACPI e SSDTs Explicados

Entenda o que cada SSDT faz e quando usar

O que é ACPI?
ACPI (Advanced Configuration and Power Interface) é uma especificação que define tabelas de hardware para o sistema operacional. SSDTs são tabelas secundárias que adicionam ou modificam funcionalidades.

SSDT-EC-USBX

O que faz:

  • Cria um Embedded Controller (EC) fake
  • Injeta propriedades USB power
  • Necessário para boot no Catalina+

Quando usar:

  • Desktop: SEMPRE (obrigatório)
  • Laptop: Use SSDT-EC-LAPTOP

SSDT-PLUG

O que faz:

  • Habilita XCPM (XNU CPU Power Management)
  • Permite gerenciamento nativo de energia da CPU
  • Melhora performance e economia de energia

Quando usar:

  • Intel Haswell (4ª gen) ou superior
  • NÃO usar em AMD (use DummyPowerManagement)
  • Para Alder/Raptor Lake: use SSDT-PLUG-ALT

SSDT-AWAC

O que faz:

  • Força uso do RTC (Real Time Clock) legado
  • Desabilita AWAC (novo clock do firmware)
  • Previne kernel panic no boot

Quando usar:

  • Intel 300 series (Z390, B360, H370)
  • Intel 400/500/600 series
  • Se tiver kernel panic relacionado a RTC

SSDT-PMC

O que faz:

  • Adiciona device PMCR ao ACPI
  • Corrige NVRAM nativo em 300 series
  • Melhora compatibilidade de sleep

Quando usar:

  • Intel 300 series (Z390, B360, H370)
  • Se NVRAM não funcionar nativamente

Como Compilar SSDTs

Use SSDTTime para gerar automaticamente

# Download SSDTTime git clone https://github.com/corpnewt/SSDTTime cd SSDTTime python3 SSDTTime.command # Opções disponíveis: # 1. FixHPET - Fix HPET IRQ conflicts # 2. FakeEC - Cria fake EC # 3. PluginType - Gera SSDT-PLUG # 4. PMC - Gera SSDT-PMC # 5. AWAC - Gera SSDT-AWAC # 6. USB Reset - Gera SSDT-RHUB

SSDT-PMC

O que faz:

  • Corrige NVRAM nativo em placas 300-series (não-Z370)
  • Declara o chip FW como MMIO no ACPI
  • Permite que o kernel reconheça a região NVRAM

Quando usar:

  • Placas 300-series verdadeiras (B360, B365, H310, H370, Z390)
  • NÃO usar em Z370 (já tem NVRAM nativo)

SSDT-RHUB

O que faz:

  • Reseta o USB controller (RHUB)
  • Corrige problemas de USB em placas 400/500-series
  • Necessário para algumas placas AMD

Quando usar:

  • Intel 400/500/600-series (Comet Lake+)
  • AMD X570, B550, A520

SSDT-PNLF (Laptops)

O que faz:

  • Habilita controle de brilho do painel LCD
  • Cria device PNLF para backlight
  • Permite ajuste via teclas Fn

Quando usar:

  • TODOS os laptops com iGPU Intel
  • NÃO necessário em desktops

SSDT-GPI0 (Laptops)

O que faz:

  • Habilita trackpad I2C
  • Cria stub GPIO para VoodooI2C
  • Melhora gestos multi-touch

Quando usar:

  • Laptops com trackpad I2C
  • Alternativa ao SSDT-XOSI (mais seguro)

SSDT-CPUR (AMD)

O que faz:

  • Corrige detecção de CPU em placas B550/A520
  • Declara todos os cores da CPU
  • Necessário para boot em algumas placas

Quando usar:

  • AMD B550 e A520 APENAS
  • NÃO usar em X570, B450, X470, etc.

DeviceProperties (GPU Patching)

Configuração essencial para iGPU Intel (Intel HD/UHD Graphics).

Aceleradora Gráfica (iGPU)

PciRoot(0x0)/Pci(0x2,0x0) ├── AAPL,ig-platform-id | Data | 07009B3E ├── device-id | Data | 9B3E0000 ├── framebuffer-patch-enable | Data | 01000000
Atenção: GPUs AMD dedicadas geralmente não precisam de DeviceProperties, apenas boot-args ou SSDTs!

Kernel Quirks

Patches aplicados diretamente ao kernel do macOS.

  • AppleXcpmCfgLock: Necessário se CFG-Lock estiver habilitado na BIOS
  • DisableIoMapper: Necessário se VT-d estiver habilitado na BIOS
  • PanicNoKextDump: Evita reboot instantâneo em Kernel Panic (essencial para debug)
  • XhciPortLimit: Desabilite após mapear USBs (macOS 11.3+)

Misc (Segurança & Boot)

Configurações críticas de segurança e comportamento de inicialização.

Security

  • SecureBootModel: Default (x86legacy se Monterey+ em PCs antigos). 'Disabled' para instalar versões antigas.
  • Vault: Optional (desabilitado). 'Secure' exige assinatura de todos os arquivos.
  • ScanPolicy: 0 (detectar tudo). Altere se quiser ocultar partições NTFS/Linux.

Boot

  • Timeout: Tempo em segundos antes do boot automático (ex: 5).
  • ShowPicker: True (mostrar menu). False para boot direto.

NVRAM (Boot-args)

Argumentos comuns de inicialização (boot-args).

Argumento Descrição
-v Modo Verbose (mostra logs de texto no boot). Essencial para debug.
debug=0x100 Evita reboot automático em caso de Kernel Panic.
keepsyms=1 Mostra símbolos de debug no Kernel Panic (ajuda a identificar a causa).
alcid=1 Layout ID padrão para AppleALC. Mude o número conforme seu codec.
agdpmod=pikera Necessário para GPUs AMD Navi (RX 5000/6000/7000). Corrige tela preta.
amfi=0x80 Desabilita AMFI (Necessário para OCLP em Sonoma/Sequoia).

Recomendações por Plataforma

💻 Laptops (Intel)

  • DeviceProperties: Essencial configurar Framebuffer Patching para iGPU (tela preta/glitches).
  • NVRAM: Adicione -igfxblr se tiver problemas de backlight no boot.
  • Kernel: Habilite PanicNoKextDump. Laptops são mais propensos a panics.

🖥️ Desktops (AMD)

  • Kernel: Aplique os Patches de Kernel para AMD Ryzen (obrigatório).
  • Boot-args: npci=0x2000 ou npci=0x3000 geralmente necessário para evitar travar no início.

Troubleshooting Avançado

Diagnóstico e solução de problemas complexos

Entendendo Kernel Panics

Se o PC reinicia antes de carregar:

  1. Adicione debug=0x100 keepsyms=1 aos boot-args
  2. Adicione -v para modo verbose
  3. Filme a tela no momento do travamento

Erros Comuns:

  • [EB|#LOG:EXITBS:START]

    Erro de Booter Quirks. Verifique RebuildAppleMemoryMap, SetupVirtualMap ou EnableWriteUnprotector.

  • AppleNVMe Assert failed

    Use NVMeFix.kext ou verifique compatibilidade do SSD.

  • apfs_module_start...

    Erro no driver APFS ou BIOS (EC não configurado corretamente).

Problemas Gráficos (GPU)

  • Tela Preta (Boot): Adicione agdpmod=pikera (APENAS se não usar NootRX). Verifique se WhateverGreen está carregado.
  • Sem Aceleração (Dock opaco): GPU não suportada ou kexts não carregados. AMD requer Lilu+WhateverGreen (ou NootRX). Intel requer DeviceProperties corretos.
  • Tela Rosa/Verde: Force modo RGB nas configurações do monitor ou use patch EDID.

Áudio (AppleALC)

Se o áudio não funcionar mesmo com AppleALC e alcid:

  1. Verifique se o HPET está corrigido (SSDTTime FixHPET)
  2. Confirme se o controlador de áudio aparece no Hackintool
  3. Tente boot-arg alcdelay=1000 (atrasa carregamento)

🚫 Problemas de Boot Específicos

Travado em [EB|#LOG:EXITBS:START]:
  • Problema com Booter Quirks. Tente habilitar DevirtualiseMmio
  • Verifique RebuildAppleMemoryMap e SyncRuntimePermissions
  • Para Z390+: Desabilite SetupVirtualMap
Travado em "Waiting for Root Device":
  • Problema USB: Tente portas USB 2.0 diferentes, use USBInjectAll.kext temporariamente
  • Problema SATA: Verifique se SATA está em modo AHCI (não RAID/IDE)
  • NVMe problemático: Adicione NVMeFix.kext (PM981/PM991)

🔌 Problemas de USB

Limite de 15 Portas:
macOS tem limite de 15 portas USB por controlador. Use USBMap ou USBToolBox para mapear corretamente.
XhciPortLimit:
  • macOS 11.3+: XhciPortLimit NÃO funciona mais!
  • Use USBInjectAll.kext + mapeamento manual
  • Ou use USBToolBox.kext (recomendado)

Passo a Passo para Mapear USB:

  1. Baixe USBToolBox (Windows) ou USBMap (macOS)
  2. Identifique todas as portas USB testando com pendrive
  3. Selecione as 15 portas mais importantes (USB 2.0 + USB 3.0)
  4. Gere USBMap.kext ou UTBMap.kext
  5. Remova USBInjectAll.kext e desabilite XhciPortLimit

✅ Problemas Pós-Instalação

Sleep/Wake Issues:

  • Não entra em sleep: Verifique pmset -g assertions para ver o que está impedindo
  • Wake imediato: Desabilite Wake on LAN na BIOS, use pmset -a darkwakes 0
  • USB wake: Adicione SSDT-GPRW ou SSDT-PTSWAK
  • Bluetooth wake: Desabilite em Preferências do Sistema

iServices (iMessage/FaceTime):

Verifique:
  • Serial Number válido mas NÃO em uso (verifique em checkcoverage.apple.com)
  • En0 (Ethernet) como interface primária
  • ROM = endereço MAC da placa de rede
  • MLB válido e correspondente ao Serial

Áudio não funciona:

  1. Verifique se AppleALC.kext está carregado (kextstat | grep AppleALC)
  2. Teste diferentes layout IDs (alcid=1, alcid=2, etc.)
  3. Verifique se HPET está corrigido (SSDT-HPET)
  4. Consulte codecs suportados

Glossário de Termos

Definições de termos técnicos do Hackintosh

A

ACPI

Advanced Configuration and Power Interface - Interface padrão para gerenciamento de energia e configuração de hardware

AML

ACPI Machine Language - Formato compilado de arquivos SSDT/DSDT

B

Boot-args

Argumentos de inicialização passados ao kernel do macOS para modificar comportamento

D

DSDT

Differentiated System Description Table - Tabela principal do ACPI que descreve o hardware

DRM

Digital Rights Management - Tecnologia de proteção de conteúdo digital (Netflix, Apple TV+)

E

EFI

Extensible Firmware Interface - Partição especial que contém o bootloader e arquivos de configuração

K

Kext

Kernel Extension - Drivers do macOS que estendem funcionalidades do kernel

Kernel Panic

Erro crítico do kernel que causa reinicialização do sistema

N

NVRAM

Non-Volatile Random Access Memory - Memória que armazena configurações do sistema mesmo após desligar

O

OpenCore

Bootloader moderno e seguro para Hackintosh, sucessor do Clover

Q

Quirk

Correção ou patch específico para resolver incompatibilidades de hardware

S

SMBIOS

System Management BIOS - Define qual modelo de Mac seu Hackintosh vai emular

SSDT

Secondary System Description Table - Tabelas secundárias do ACPI que adicionam ou modificam funcionalidades

U

UEFI

Unified Extensible Firmware Interface - Substituto moderno do BIOS legado

V

Verbose Mode

Modo de inicialização que mostra log detalhado do boot (boot-arg: -v)
